# Sports Research Tool

A starter Streamlit-based sports analytics app.

This project includes:
- A home hub (`app.py`)
- Multiple Streamlit pages (Player Dashboard, Game Log Explorer, EV Engine, Data Model Viewer, API Tools, Hosted App)
- Utility functions for EV and metrics
- A clean folder structure ready for expansion

Deploy on Streamlit Cloud and add it to your home screen for daily use.
